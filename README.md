# Два эффекта плашки «Рекомендация»

Откройте `index.html` в браузере. «Повторить» запускает переход от скелетона к плашке. «Длинный текст» показывает переносы. Сборка и зависимости для демо не требуются.

## Что взять для переноса

- **Текст.** Функция `animatedRecommendationText` в `effects.js` и стили для `.recommendation-copy`, `.recommendation-animated-visual`, `.recommendation-word` и `.recommendation-letter` в `effects.css`, включая обе анимации и правило `prefers-reduced-motion`. Заголовок и основной текст стартуют вместе. Шаг между символами 3 мс, движение каждого занимает 320 мс, смена цвета 270 мс. Переносятся целые слова.
- **Фон.** Константа `RECOMMENDATION_DUST`, вычисление `recommendationParticlesAt` и отрисовка `initRecommendationDust` в `effects.js`. Canvas лежит поверх градиента, под текстом. Частицы живут 700 мс, яркость достигает пика на 55% жизни. Цвет #BAA8FF, интенсивность 90%, масштаб 140%. При уменьшенном движении остаётся статичный первый кадр.

Оба эффекта воспроизводят параметры прототипа. Демо использует системный шрифт и нейтральный текст. Для совпадения типографики в целевом интерфейсе настройте YS Text 14/18, начертания 500 и 400, отступ между заголовком и текстом 2 px.

Лицензия стороннего фрагмента указана в `THIRD_PARTY_NOTICES.md`.
